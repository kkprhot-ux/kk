## 1. 项目概述

### 1.1 一句话定位

打电话时，**AI 实时听客户说话，< 2 秒给您推荐应对话术**；电话挂断后，自动生成复盘。专为**电话销售**设计。

### 1.2 核心价值

- 🎯 **应对话术实时推送**：客户每说完 1-2 句，AI 立刻给您建议
- 📊 **通话后自动复盘**：客户关注点、您的表现、待改进点
- 💰 **零成本复刻**：参考 900 元/年的同类产品（科大讯飞等），**数据本地化**

### 1.3 调研依据

参考 2 个互补的开源项目：
- **fluxions-ai/vui** (747 ⭐) - 实时语音架构
- **ptc31141-maker/ai-tob-sales-copilot** (2 ⭐) - ToB 销售辅助功能

完整调研报告：2026-08-25-github-research-report.md

### 3.2 数据流（实时话术 7 步）

| # | 步骤 | 在哪 | 发生了什么 | 延迟目标 |
|---|---|---|---|---|
| 1 | 📞 通话开始 | 手机 | Flutter 检测到电话状态变化 | - |
| 2 | 🎙️ 音频采集 | 手机 | 麦克风捕获通话音频 | - |
| 3 | 🔇 VAD 检测 | 手机 | 静音 → 攒句；说话 → 推流 | < 100ms |
| 4 | 📝 ASR 转写 | 云端 | 讯飞流式转写（实时） | 500-1000ms |
| 5 | 🤖 LLM 分析 | 云端 | DeepSeek 多 agent 分析 | 500-800ms |
| 6 | 📣 话术推送 | 电脑→手机 | WebSocket 推到手机显示 | < 100ms |
| 7 | 📱 屏幕显示 | 手机 | 用户看到推荐话术 | - |
| **总计** | | | | **< 2 秒** |

## 4. 核心功能流程

### 4.1 实时话术推荐（核心）

#### 4.1.1 触发逻辑
- VAD 检测到客户说话 → 攒到 1-2 句（不每句都触发）
- 静音 0.8-1.5 秒 → 立即触发分析
- 太长（如超过 30 字未静音）→ 也强制触发

#### 4.1.2 多 Agent 分析（参考 LangGraph）

\\\python
# 第一版简化为单 agent 并行调用
analysis = llm.analyze(
    customer_text="...",
    conversation_history=last_3_exchanges,
    context={
        "current_scenario": "cold_call|follow_up|negotiation|closing",
        "product_info": "...",
        "user_role": "销售"
    }
)
\\\

返回：
\\\json
{
  "scenario": "异议处理",         // 当前场景
  "intent": "客户在比价",          // 客户意图
  "objection": "价格偏高",         // 异议
  "emotion": "犹豫",              // 客户情绪
  "recommended_script": "..."   // 推荐话术
}
\\\

#### 4.1.3 话术分场景（参考 sales-copilot）

| 场景 | 说明 | 推荐话术风格 |
|---|---|---|
| 开场白 | 冷开发/电话接通 | 简短自我介绍 + 价值点 |
| 需求探询 | 客户在描述需求 | 深度追问 |
| 产品介绍 | 介绍功能 | FAB（特性-优势-利益） |
| 异议处理 | 客户在反对/犹豫 | 共情 + 化解 |
| 价格谈判 | 谈钱 | 价值锚定 + 让步策略 |
| 逼单 | 推进成交 | 紧迫感 + 风险逆转 |
| 结束 | 收尾 | 下一步明确约定 |

## 8. 已知风险与缓解

### 8.1 < 2 秒延迟风险
- **风险**：网络抖动时可能超 2 秒
- **缓解**：
  - 流式 ASR（不等整段结束）
  - 段落级触发（不是字符级）
  - 提前 prefill LLM
  - 失败时显示"思考中..."

### 8.2 ASR 准确度风险
- **风险**：客户口音/专业术语可能识别错
- **缓解**：
  - 使用讯飞（中文准）
  - 销售场景可定制术语库（第二版）
  - 错误时用户可手动修正（第二版）

### 8.3 LLM 话术质量风险
- **风险**：AI 推荐话术可能不专业
- **缓解**：
  - 基于 sales-copilot 的销售方法论 prompt
  - 持续优化 prompt
  - 用户可标记"不实用"反馈（第二版）

### 8.4 通话隐私风险
- **风险**：通话录音涉及隐私
- **缓解**：
  - 通话录音**临时缓存**，通话结束后**默认删除**
  - 文字永久留（用户可见）
  - 通话前提示用户"将启动 AI 辅助"

### 8.5 入门级电脑性能
- **风险**：电脑端处理慢
- **缓解**：所有重活（ASR、LLM）都在云端，电脑只做轻处理
